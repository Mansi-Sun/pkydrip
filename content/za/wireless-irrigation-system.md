## Problem

Growing farms need to add irrigation zones — but wired expansion is expensive and slow.

- Cable installation cost limits farm expansion
- New zones need control without trenching new lines
- Off-grid farms need simple, low-maintenance communication
- Wireless must be reliable enough for daily irrigation operation

## Solution

Low-cost wireless irrigation control designed for **practical farm expansion** — add valve zones without major cable infrastructure investment.

## Features

- Wireless valve node control for distributed zones
- Low installation cost compared to wired systems
- Expandable as farm grows — add nodes over time
- Compatible with solar pump and control system integration
- Simple field maintenance for rural operators

## Applications

- Farms adding new irrigation blocks
- Off-grid farms with spread-out valve locations
- Retrofit projects expanding from central pump station
- Fruit and crop farms scaling irrigation coverage

## South Africa Value

- Significantly lower expansion cost vs wired valve control
- Grow irrigation coverage incrementally as budget allows
