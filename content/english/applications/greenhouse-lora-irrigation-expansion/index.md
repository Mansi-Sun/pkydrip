# Greenhouse LoRa Irrigation Expansion Project

A practical irrigation expansion case using LoRa wireless valve controllers in a greenhouse environment.

---

## Project Background

In many greenhouse projects, the irrigation system is already installed with pipelines and basic infrastructure.

However, when growers need to expand irrigation zones, traditional solutions require:

- New control cables  
- Additional trenching work  
- Modifications to the electrical system  

This increases both cost and complexity, especially in operating greenhouses.

---

## System Structure

The expansion is implemented using a LoRa wireless irrigation control system:

- LoRa gateway (central communication unit)  
- Wireless valve controllers installed in the field  
- Pulse solenoid valves for irrigation control  
- Solar-powered operation for each control node  

This structure allows centralized control without additional wiring.

## Expansion Strategy

In this project:

- Three new irrigation zones were added  
- Each zone is controlled by a wireless valve controller  
- Each controller operates a 1" pulse solenoid valve  

Instead of installing new control cables, the system expansion only required extending the irrigation pipelines.

A LoRa gateway installed at the top of the greenhouse ensures stable communication between all nodes.

This allows the system to be expanded without affecting the existing infrastructure.
