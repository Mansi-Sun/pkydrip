## Product Overview

**PKY-EVC01** is an electric valve controller designed for irrigation projects where:
- Stable power supply is available
- Wired or cellular communication is preferred
- Valves need reliable and centralized control

It provides a flexible execution solution for both **4G-based cloud control** and **RS485-based system integration**.

---

## Communication Options

### 4G Mode – Direct Cloud Connection

In 4G mode, PKY-EVC01 connects directly to the cloud platform:
- No local controller required
- Suitable for distributed sites with mobile network coverage
- Remote valve control and status monitoring via cloud or app

---

### RS485 Mode – Integrated System Control

In RS485 mode, PKY-EVC01 connects to:
- **PKY-60W** main controller
- **PKY-IC03** wireless execution controller (system dependent)

This mode is ideal for:
- Centralized control cabinets
- Engineering projects with structured wiring
- Scenarios requiring unified logic and scheduling

---

## Valve Compatibility

PKY-EVC01 is designed to control:
- Electric valves
- Motorized valves
- Solenoid valves (AC/DC, system dependent)

Valve type and voltage are configurable based on project requirements.

---

## Role in the PKYDrip System

PKY-EVC01 belongs to the **execution layer** of the PKYDrip architecture.

Compared with solar LoRa devices:
- It relies on wired power instead of solar
- It uses RS485 or cellular communication instead of LoRa
- It is suitable for locations with stable infrastructure

This clear separation helps system designers choose the correct device for each field condition.
