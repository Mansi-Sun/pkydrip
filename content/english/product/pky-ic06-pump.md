## Product Overview

The **PKY-IC06-PUMP** is a wireless pump control device designed for irrigation projects where:

- Water sources are far from the farm or control room
- Public networks (4G / WiFi) are unavailable or unreliable
- Manual pump operation causes time loss and uncertainty

Using **LoRa long-range communication**, PKY-IC06-PUMP allows operators to remotely start and stop water pumps without relying on cellular networks.

---

## Key Advantages

### Remote Pump Control without Public Networks

PKY-IC06-PUMP communicates via LoRa, making it suitable for:

- Remote wells and reservoirs
- Mountainous or open-field areas
- Regions with no stable mobile coverage

This eliminates the need for frequent on-site visits just to operate pumps.

---

### Pump Operation Verification via Flow Feedback

Unlike simple remote switches, PKY-IC06-PUMP supports **flow sensor integration at the pump outlet**.

This enables the system to:
- Confirm whether the pump has actually started
- Detect abnormal conditions (no flow after start command)
- Improve operational reliability

**Control is no longer blind — pump operation is verifiable.**

---

### Measurement-Oriented Control Logic

By combining pump control with flow detection, the system shifts from basic switching to measurable operation:

- Pump start/stop status is confirmed
- Water output can be monitored
- Operational records can be generated

This greatly improves system stability for unattended irrigation sites.

## System Architecture Example

A typical setup includes:
- PKY-EG08 LoRa Gateway
- PKY-IC06-PUMP Pump Controller
- Solar-powered pump or AC pump with control relay
- Flow sensor installed at pump outlet

This architecture provides reliable pump control and operation confirmation.
