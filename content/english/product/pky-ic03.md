## Role in the Irrigation System

PKY-IC03 is a **LoRa wireless field controller** used as a **valve execution node** in a modular irrigation system.

It is designed to:
- Operate solenoid valves in distributed zones
- Run scheduled tasks in the field
- Receive remote commands via a LoRa gateway and upper-level system

PKY-IC03 is not a main logic controller.  
It executes tasks as part of a larger, expandable architecture.

---

## Where PKY-IC03 Fits

In a complete system:

- **Main Controller (optional)**  
  Defines irrigation logic, zones, schedules, and automation rules

- **PKY-EG08 (LoRa Gateway)**  
  Coordinates LoRa communication and manages wireless terminal devices

- **PKY-IC03 (LoRa Field Node)**  
  Opens/closes valves and executes assigned actions in each zone

Each block operates independently within an expandable irrigation control system.

---

## Core Capabilities

- Stable LoRa connection when paired with PKY-EG08
- Battery-powered operation for off-grid deployments (solar optional)
- Supports timer schedules and remote commands (via system platform)
- Low-power design for long field operation
- Designed for large-area, cable-free irrigation zoning

---

## Control Modes

PKY-IC03 supports multiple control methods (system dependent):

- **Timer-based schedules**
- **Remote commands** via cloud/platform through the LoRa gateway
- **Local trigger inputs** using sensor signals

It can be deployed as a simple wireless valve node or as part of a larger automation system.

---

## Power & Deployment

Designed for remote and off-grid environments:

- DC 9V supply options
- Battery operation (solar rechargeable design)
- Optional solar panel for extended deployments

This makes PKY-IC03 suitable for farms or landscapes where trenching and cabling are difficult.

---

## Typical Applications

- Orchards: distributed irrigation zones without long wiring runs
- Mountain farms: terraced or sloped fields with limited infrastructure
- Urban landscaping: parks, roadside greenery, riverbanks, remote green belts

---

## Expandability & System Growth

**Start Simple. Upgrade Anytime.**

A project can start with a small number of wireless zones and expand gradually:
- Add more IC03 nodes for additional zones
- Add sensors for local triggers
- Integrate with a main controller for full irrigation logic
- Extend remote management via cloud platform integration

---

## Integration Notes (For Engineers)

- PKY-IC03 is designed to pair with **PKY-EG08** as the LoRa gateway
- Zone capacity depends on the LoRa network design and project layout
- Valve type and wiring should match the selected solenoid valve specification
- Sensor-trigger control depends on selected sensor type and integration plan
