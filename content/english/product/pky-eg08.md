## Role in the Irrigation System

PKY-EG08 is a **wireless irrigation gateway**.  
It acts as the **master coordination node** in a LoRa-based irrigation network.

The gateway does not directly control irrigation logic or pumps.  
Its role is to **manage LoRa terminal devices** and **bridge wireless field devices** with higher-level control systems.

## Part of a Wireless Irrigation System

This product is designed as part of the PKYDrip LoRa wireless irrigation control system.

It works together with:

- LoRa Irrigation Gateway
- Wireless Valve Controllers
- Optional solar power modules

## Where PKY-EG08 Fits

In a modular irrigation system:

- **Main Controller**  
  Handles irrigation logic, zones, schedules, and automation rules

- **PKY-EG08 (LoRa Gateway)**  
  Coordinates LoRa communication and manages wireless terminal devices

- **LoRa Valve Controllers / Field Nodes**  
  Execute valve actions and report status

- **Upper-Level Systems**  
  PLCs, SCADA systems, or cloud platforms connected via RS485 or UART

Each module operates independently while forming a scalable system.

---

## Core Functions

- Acts as the central hub of a LoRa irrigation network
- Manages multiple wireless terminal devices
- Provides long-range communication for distributed fields
- Bridges LoRa field devices with wired control or cloud systems
- Supports both local and remote system architectures

---

## Communication & Integration

PKY-EG08 supports multiple integration methods:

- **LoRa**  
  Long-range wireless communication with terminal devices (up to ~2.5 km in open areas)

- **RS485 / UART**  
  Direct integration with:
  - Main irrigation controllers
  - PLC or SCADA systems
  - Local servers or cloud gateways

This flexibility allows EG08 to be used in both standalone and platform-based solutions.
