- Use the **Pump Sizing Calculator** if you already know the irrigation type and want a quick estimate.

- Use the **Sprinkler Gun Chart** if you are comparing pressure, distance, and pump direction for gun sprinklers.
- Use the **Guided Wizard** if you are not sure where to start.
