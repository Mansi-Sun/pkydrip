## How To Choose the Right Tool

- Start with the **Guided Wizard** if you are not sure where to begin.
- Use the **Calculator** if you already know some pump or irrigation parameters.
- Use the **Request Form** if you want PKYDrip to review the project direction.
- Use the **Sprinkler Gun Chart** if you are comparing sprinkler gun requirements.
