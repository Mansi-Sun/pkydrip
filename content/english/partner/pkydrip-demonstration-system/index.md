# PKYDRIP Irrigation Demonstration System

**Contractor Training & Partner Demonstration Platform**

The PKYDRIP Demonstration System is a **fully operational irrigation automation platform** designed for:

- irrigation contractors  
- agricultural system integrators  
- project partners  
- distributors  

Unlike a traditional showroom, this system demonstrates the **complete irrigation control architecture** in real operation.

This demonstration platform is intended to be deployed in regions such as:

- Australia  
- Dubai  
- Saudi Arabia  
- Southeast Asia  

The goal is to allow contractors and partners to **observe, test and understand irrigation automation in real working conditions**.

---

# System Architecture

![System Architecture](/images/demo/pkydrip-demo-architecture.svg)

The demonstration system simulates a real irrigation project including:

- water source
- pump system
- pipeline
- sensors
- irrigation controller
- irrigation zones

Sensors installed in the system allow contractors to observe real operational data.

---

# Sequential Irrigation Logic

![Sequential Valve Logic](/images/demo/pkydrip-demo-sequential-logic.svg)

The PKYDRIP controller runs irrigation zones **sequentially**.

Example:

Zone 1 → irrigation  
Zone 2 → irrigation  
Zone 3 → irrigation  

Only one valve runs at a time.

This provides:

- stable pressure
- smaller pump requirement
- lower pipeline cost
- reliable irrigation operation

---

# System Functional Blocks

![System Functions](/images/demo/pkydrip-demo-functions.svg)

The demonstration platform shows the core automation capabilities of the PKYDRIP system.

### Automatic Irrigation

The controller automatically starts irrigation according to preset schedules.

---

### Sequential Valve Irrigation

Multiple irrigation zones are operated sequentially.

---

### Irrigation Scheduling

Supported irrigation plans include:

- daily irrigation
- weekly irrigation
- multiple irrigation cycles per day

---

# System Monitoring

The system displays real-time operational data.

### System Status

- controller running status
- irrigation program status

### Pump Status

- pump start
- pump stop

### Flow Monitoring

- real-time flow rate
- accumulated flow volume

### Pressure Monitoring

- pipeline pressure

### Valve Status

- valve open
- valve closed

---

# Protection Functions

The platform demonstrates system safety logic.

### Over Pressure Protection

The system detects abnormal pipeline pressure and stops irrigation automatically.

---

### Low Flow Protection

Low flow may indicate water shortage or pipeline blockage.

The controller will stop the system to prevent damage.

---

# Core Equipment (BOM)

| Component | Description |
|---|---|
| Irrigation Controller | PKYDRIP main irrigation controller |
| Solenoid Valves | 24V DC irrigation solenoid valves |
| Flow Sensor | irrigation flow monitoring |
| Pressure Sensor | pipeline pressure monitoring |
| Pump | demonstration pump |
| Automatic Relief Valve | pressure safety protection |
| Sprinklers | irrigation demonstration zones |
| Water Tank | demonstration water source |

---

# Wiring Diagram

![Wiring Diagram](/images/demo/pkydrip-demo-wiring.svg)

Typical wiring includes:

- controller to pump relay
- controller to zone valves
- controller to flow sensor
- controller to pressure sensor

Actual wiring should follow controller specifications and local electrical standards.

---

# Demonstration Rack Structure

The demonstration system is usually installed on a **compact training rack** including:

- irrigation controller panel
- valve manifold
- sensors
- pump unit
- sprinkler demonstration zone
- water return tank

Water is circulated within the system to allow **continuous demonstration without water waste**.

---

# Expansion Modules

The demonstration system can be expanded to include additional modules.

### Remote Control

- remote irrigation monitoring

### Solar Irrigation
