# Australia Demonstration Farm Program

We are selecting **1–2 real operating farms** in Australia this season.

PKYDrip is building local demonstration partners — **real working farms**, not showroom-only setups.  
If you operate **10–80 acres** and want to upgrade irrigation automation, we want to document your system as a real Australian case.

---

## Who this is for

You are a good fit if you:
- Operate a farm long-term (not a temporary trial site)
- Want **remote control** and **repeatable irrigation scheduling**
- Have (or plan to have) a pump + valves system (drip, sprinkler, or mixed)
- Care about reducing labor, improving consistency, and managing water better

Typical farm size:
- **10–80 acres** (4–32 hectares)

---

## What selected partners receive

Selected demonstration partners receive:

- **Special equipment pricing** (demo partner level)
- **Engineering support** (system structure + module selection)
- **Local exposure** on our website & materials  
  (We publish it as a real Australian reference case)

---

## What we document (case output)

We will document the project as a real Australian case, including:
- System structure diagram (pump + main line + zones)
- Module list (controller, valve modules, comms, optional safety)
- Basic wiring / control logic (safe pump + sequential zones)
- Photos / short clips of operation
- Setup notes (what worked, what to optimize)

This becomes a reusable template for similar farms in Australia.

---

## Typical system structure (safe & standard)

A common “starter” automation structure:

1) Pump starts first → pressurize main line  
2) Zones run **one-by-one** (sequential scheduling)  
3) After last zone → pump stops automatically  
4) Optional upgrades: flow/pressure safety, sensors, fertigation

This approach:
- Keeps pressure stable
- Reduces risk of pipe burst
- Allows a smaller, more efficient pump
- Fits real farms and retrofit projects

## Basic requirements (to avoid wasted time)

To qualify, you should be able to provide:
- Farm location (City/State)
- Farm size (acres/hectares)
- Crops (or application: pasture / orchard / vegetables / mixed)
- Water source (tank / bore / river / dam)
- Pump voltage / power (or nameplate photo)
- Existing irrigation type (drip / sprinkler / mixed)

If you don’t know all details today — that’s fine.  
We can start with the basics and refine.
