# What We Typically Build

Standard safe automation structure:

1) Pump starts first  
2) Main line pressurized  
3) Valves run sequentially  
4) Pump stops after final zone  
5) Optional: pressure / flow safety modules  

This structure:
- Keeps pressure stable  
- Reduces risk  
- Fits retrofit farms  
- Easy to scale
