# Australia Demonstration Contractor Program

We are selecting **1–2 irrigation contractors or equipment dealers** in Australia to build real automation demonstration projects.

This is not a simple reseller program.  
This is a **technical collaboration program** to build repeatable project structures for Australian farms.

---

## Who this program is for

You are a good fit if you:

- Actively operate in irrigation (installation / service / integration)
- Serve real farms (10–100+ acres typical range)
- Install pumps, valves, or control systems
- Want to expand into structured irrigation automation
- Prefer long-term cooperation over one-time sales

---

## What we offer

Selected demonstration contractors receive:

- **Special partner pricing**
- **Engineering support (system structure + module planning)**
- **Control logic assistance (pump + valve sequencing)**
- **Co-branded case promotion**
- Listing on PKYDrip website as local demonstration partner

---

## What we build together

The goal is to create a real Australian reference case including:

- Pump + trunk line + multi-zone automation
- Sequential valve control logic
- Safe pump start/stop integration
- Optional: pressure / flow safety logic
- Optional: remote monitoring or cloud layer

We document:

- Structure diagram
- Module list
- Installation logic
- Site photos
- Performance notes

This becomes a **replicable template** for future projects.

---

## Why this matters for contractors

Instead of:

• Selling loose components  
• Competing only on price  

You can offer:

• Structured automation packages  
• Modular upgrade paths  
• Remote-ready systems  
• Standardized control logic  

This increases:
- Project consistency
- Service value
- Long-term maintenance revenue

---

## Basic requirements

To qualify, you should provide:

- Company name
- Location (City / State)
- Type (Contractor / Dealer / Integrator)
- Typical farm size served
- Typical irrigation type (drip / sprinkler / pivot / mixed)
- Monthly project volume (approximate)
- Interest level (demo farm / greenhouse / retrofit)
