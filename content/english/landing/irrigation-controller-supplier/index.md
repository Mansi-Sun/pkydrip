## Features

### What this controller can do

- **Automatic pump start / stop** — Start the pump when irrigation runs, stop when zones finish, and support practical interlocks via project wiring and sensor logic.  
- **Irrigation zone valve control** — Control valves by zone with sequential operation (typical for farms) or grouped operation depending on project requirements.  
- **Pressure and flow monitoring** — Use pressure/flow inputs for alarms and operational verification (e.g. abnormal pressure, no-flow after pump start).  
- **Practical farm irrigation automation** — Designed for contractors and integrators who need a controller that fits real field panels, pumps, and valve manifolds.

## System capability

### Typical system structure

**Pump → Controller → Valves (Zones) → Pressure / Flow Sensors**

This structure helps automate irrigation execution and add measurement feedback without redesigning the hydraulic system.

### Integration scope

- Pump contactor / relay start signal (project wiring)  
- Solenoid valves or valve actuators (by output type)  
- Pressure sensor input (analog / RS485, model-configured)  
- Flow sensor input (pulse / RS485, model-configured)  

### Suitable projects (quick check)

**Fit**

- **1 pump** (or a pump station where start/stop signal integration is required)  
- **Multiple irrigation zones** (valves/manifolds)  
- A need to **monitor pressure and/or flow** for reliability and troubleshooting  
- A requirement for **B2B deployment** (farm operations, greenhouse integration, contractor installation)  

**Not a fit**

If you only need a small home garden timer or low-cost consumer controller, this product is not the right fit.

## FAQ

**Can this controller start/stop a farm pump?**  
Yes. It supports pump start/stop control via project wiring (typically a relay/contactor control signal). Share pump power and control panel details so we can recommend a suitable interface method.

**Does it support pressure sensors?**  
Yes. Pressure monitoring can be integrated using appropriate sensor signal types depending on configuration (commonly analog or industrial fieldbus options).

**Does it support flow sensors?**  
Yes. Flow monitoring is supported for operational verification and alarms. Sensor type and wiring depend on the flowmeter specification.

**Is it suitable for retrofit projects?**  
Yes. It is designed for contractor installation and upgrades from manual operation to automation, especially when pump + zones + monitoring are required.

**Can it be used for drip and sprinkler systems?**  
Yes. The controller manages automation and zoning. Drip/sprinkler suitability depends on your hydraulic design, valve type, and zoning plan.

**Can PKYDrip help confirm the configuration?**  
Yes—send pump power, number of zones, valve type, and whether you need pressure/flow monitoring. We will recommend a practical configuration for your project.
