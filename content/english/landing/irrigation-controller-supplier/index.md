## Irrigation strategies — beyond timer and zone control

A basic irrigation controller starts and stops valves on a clock. The PKYDrip <strong>irrigation control system</strong> runs <strong>strategies</strong>: rules that combine time windows, sensor feedback, and outdoor weather so irrigation follows crop demand instead of a fixed schedule.

### What the irrigation controller can use

- **Zone and pump control** — sequential or grouped valves, pump start/stop, pressure and flow monitoring where specified
- **Outdoor weather station** — temperature, humidity, wind, rain, light, and **solar radiation (W/m²)** as strategy inputs
- **Solar-radiation irrigation** — start, skip, or adjust irrigation when radiation crosses a setpoint (typical for greenhouse and high-light crops)
- **Condition logic** — AND/OR rules, time windows, and averaging so a short cloud or wind spike does not fire a false cycle
- **Event log** — each run records the trigger, sensor reading, and equipment state

This is the same factory platform used for greenhouse climate: the irrigation controller is the strategy layer; pumps, valves, and cabinets execute it.

### Equipment the system can control

| Equipment | Typical use |
|-----------|-------------|
| **Wet wall / cooling pad + circulation pump** | Evaporative cooling sequenced with exhaust fans |
| **Exhaust fans** | Staged banks by temperature threshold |
| **Circulation fans** | Air mixing on schedule or condition |
| **Roll-up film / side vents** | Open/close by temperature, wind, or manual command |
| **Shade curtains** | Deploy by light intensity or solar radiation |
| **Hot-air heaters** | Cold-climate and night heating interface |
| **CO₂ sensing + generator** | Optional add-on: measure CO₂ and control generation equipment |
| **Irrigation pumps and valves** | Same cabinet family can run irrigation strategies |
| **Fertigation system link** | Connect automatic fertigation (EC/pH, dosing) on the same platform |

Software issues commands; the electrical cabinet switches motors. Sequential startup limits inrush (each group ≤ 2 kW, configurable delay) so generators and site power are not hit by every motor at once.

## FAQ

**Are you an irrigation controller supplier or a climate factory?**  
Both. This page is the factory / OEM entry for **irrigation control systems** and **greenhouse climate control systems**. Same industrial platform, configured as irrigation strategies, climate cabinets, or both.

**Is this still a timer-and-zone irrigation controller?**  
Timer and zone control remain available. The product is built for **irrigation strategies** — including weather-station data and **solar radiation** as an automatic irrigation input — not only clock schedules.

**Can the cabinet control wet walls, fans, and roll-up film?**  
Yes. Typical expansions include wet-wall pumps, exhaust fans, circulation fans, roll-up film, and shade. Cold-climate projects can add heater control. CO₂ sensing and CO₂ generation equipment are optional add-ons.

**Can it connect to an automatic fertigation system?**  
Yes. Fertigation is a linked product family on the same controller platform, with a dedicated operator interface. It is not required for a climate-only or irrigation-only cabinet.

**Do you support OEM, private label, and white label?**  
Yes. HMI branding, labels, and documentation can carry your brand. Sample and small-batch orders are available before stable SKU supply.
