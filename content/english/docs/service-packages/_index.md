## International Technical Service Packages

PKYDrip provides practical technical support for irrigation and fertigation projects, especially for customers who need system review, equipment selection, wiring logic, BOM support, or project-oriented documentation.

These service packages are designed for:

- growers with real project requirements
- irrigation contractors
- EPC companies
- distributors and regional partners

---

## What We Can Support

- Irrigation system direction review
- Fertigation system structure planning
- Controller and valve logic suggestions
- Pump and zone configuration review
- BOM preparation support
- Wiring and connection guidance
- Remote technical discussion support

---

## Typical Project Types

- Greenhouse fertigation systems
- Open-field drip irrigation projects
- Orchard irrigation systems
- Solar irrigation projects
- Remote valve control projects
- Multi-zone controller-based irrigation systems

## Typical Deliverables

Depending on the project type and service level, deliverables may include:

- System structure suggestions
- Equipment selection guidance
- Valve zoning logic
- BOM list
- Wiring diagram
- Layout recommendations
- Remote discussion support

## Service Package Levels

### Basic Package
Suitable for simple irrigation direction review and basic equipment recommendations.

### Standard Package
Suitable for projects that need BOM support, controller logic review, and more structured planning.

### Advanced / Project Package
Suitable for larger projects requiring detailed coordination, technical review, and deeper engineering support.
