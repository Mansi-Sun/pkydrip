## Irrigation Design Wizard

The Irrigation Design Wizard is a guided engineering tool designed to help users quickly define the basic structure of an irrigation system.

It is suitable for early-stage planning of:

- open field irrigation  
- greenhouse irrigation  
- orchard irrigation  
- landscape irrigation  

---

## What This Tool Does

The wizard collects key project parameters and helps:

- estimate water demand  
- identify irrigation zones  
- define pump requirements  
- prepare system structure for discussion  

This tool is especially useful before communicating with engineers or suppliers.

---

## When to Use This Tool

Use the Irrigation Design Wizard if:

- you are starting a new irrigation project  
- you are not sure how to structure the system  
- you need to organize project information  
- you want a quick system direction  

---

## Typical Input Information

During the process, you may be asked for:

- project type (open field / greenhouse / etc.)  
- irrigation area  
- water source (well / river / tank)  
- irrigation method (drip / sprinkler / gun)  
- number of zones  
- available power conditions  

You do not need perfect data — rough estimates are acceptable.

---

## What You Will Get

After completing the wizard, you will have:

- a clearer system structure  
- basic pump sizing direction  
- irrigation zoning concept  
- information ready for engineering discussion  

---

## Important Notes

This tool provides **concept-level guidance only**.

It does NOT replace:

- detailed hydraulic calculations  
- final engineering design  
- exact equipment selection
