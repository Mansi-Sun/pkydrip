## What This Tool Does

The Pump Sizing Request Form allows users to submit project information for manual review by the PKYDrip engineering team.

→ [Open Pump Sizing Request Form](/tools/pump-sizing/pump-sizing-request-form)

---

## When to Use This Tool

This tool is recommended when:

- project conditions are unclear  
- key parameters are missing  
- multiple design options are possible  
- a more reliable system direction is required  

---

## Who Should Use This Tool

- project owners with incomplete data  
- contractors preparing real projects  
- distributors supporting customer inquiries  

---

## What Information to Provide

Try to include:

- irrigation area  
- water source  
- crop type or application  
- power condition (grid / solar)  
- any known flow or pressure data  

Even partial information is acceptable.

---

## What Happens After Submission

- PKYDrip reviews the information  
- A suggested system direction is provided  
- Key missing parameters are identified  
- Further discussion may follow  

---

## Important Notes

- Response time depends on project complexity  
- This is not an instant calculator  
- Results are based on engineering experience  

---

## When Not to Use This Tool

Use the Calculator if:

- you already have clear parameters  

Use the Guided Wizard if:

- you need step-by-step guidance
