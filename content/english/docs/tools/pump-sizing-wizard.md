## What This Tool Does

The Pump Sizing Guided Wizard helps users understand the basic direction of pump selection for irrigation projects.

It is designed for early-stage planning and for users who are not yet sure what technical information is required.

→ [Open Engineering Tools](/tools/)

---

## Who Should Use This Tool

This tool is suitable for:

- growers planning a new irrigation system
- contractors preparing for project discussion
- users who do not yet know the pump size
- project owners collecting basic information before contacting PKYDrip

---

## What to Prepare Before Using It

Before starting, it helps to know:

- irrigation area size
- irrigation type
- water source
- whether the project is new or retrofit
- whether grid power, solar, or hybrid power is planned

If some of this information is not available, the wizard can still help guide the next step.

---

## How to Use It

1. Open the tool center  
2. Start the Pump Sizing Guided Wizard  
3. Answer the questions step by step  
4. Review the suggested project direction  
5. Use the result to prepare for pump discussion or system consultation  

---

## What the Result Means

The result is a preliminary engineering direction.

It may help clarify:

- approximate pump planning logic
- key parameters still missing
- whether a direct calculator is suitable
- whether manual review is needed

This is not a final pump model selection or engineering quotation.

---

## When to Use Another Tool Instead

Use the Pump Sizing Calculator if:

- you already know flow or head data
- you want a more direct estimate

Use the Pump Sizing Request Form if:

- your project is unclear
- multiple unknowns remain
- you prefer PKYDrip to review the case directly

Use the Sprinkler Gun Pump Sizing Chart if:

- your project mainly uses sprinkler gun irrigation
- you want a quick chart-based reference
