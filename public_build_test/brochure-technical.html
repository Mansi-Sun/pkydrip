Protection

Pump and Valve Protection Logic

The system is designed to avoid running the pump without an open valve and to avoid closing valves while the pump is still operating.

Typical automatic sequence

  1. Open selected valve
  2. Wait for valve delay time
  3. Start pump
  4. Run irrigation
  5. Stop pump
  6. Close valve after delay

Note: This logic helps protect pumps, pipelines, and valves during automatic irrigation.

Wireless

Wireless LoRa Valve Control Architecture

LoRa valve controllers can be used when irrigation zones are far away from the main control cabinet or when cable installation is difficult.

Control cabinet / gateway ↓ LoRa wireless Solar valve controller ↓ Solenoid / electric valve ↓ Irrigation zone
  • Suitable for remote valve stations
  • Solar and battery-powered options
  • Reduces long-distance wiring
  • Useful for orchards, hillsides, and open fields
