# PKYDrip – Development Branch (dev)

This repository contains a **development version** of the PKYDrip smart irrigation system website.

## Purpose of this branch

The `dev` branch is used for:
- Product structure refactoring
- New product and solution experiments
- Engineering documentation and guides
- Layout and navigation testing
- Future feature planning

⚠️ **This branch is NOT intended for production use.**

---

## Branch Usage Rules

- `master`  
  Stable production version (smart.pky-dripirrigation.com)

- `dev`  
  Development and experimental version

Do not merge experimental changes into `master` without review.

---

## Website Structure Notes

- `/content/`  
  Public website content (products, solutions, guides)

- `/layouts/`  
  Hugo templates and layouts

- `/static/`  
  Images, JS, CSS, assets

---

## Deployment

- Production site deploys from `master`
- Development site deploys from `dev`
