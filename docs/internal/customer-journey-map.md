# Customer Journey Map

Purpose: ensure PKYDrip Website V2 follows customer thinking instead of only engineering thinking.

This document does not modify navigation or page content. It defines how future navigation, page templates, and internal links should serve different customer types.

## Farm Owner

### Problems

- Needs reliable irrigation without becoming an automation engineer.
- Wants to reduce labor, water waste, and crop risk.
- May already have pumps, filters, tanks, valves, and pipelines.
- Often asks what system is suitable for the farm size, crop, water source, and budget.
- Needs practical confidence before contacting a supplier.

### Goals

- Understand what PKYDrip can help build.
- See similar farm applications.
- Learn whether existing equipment can be upgraded.
- Get a recommended system direction.
- Contact PKYDrip with enough project details.

### Recommended Entry Pages

- Home
- Solutions index
- Open Field Irrigation
- Orchard Irrigation
- Solar Powered Irrigation
- Irrigation Retrofit Upgrade
- Core System pages
- Contact

### Navigation Path

Home
→ Solutions
→ Relevant crop/application page
→ System page
→ Contact

Alternative path:

Home
→ What We Help You Build
→ Core Systems
→ Contact

## Greenhouse Grower

### Problems

- Needs more accurate fertigation, EC/pH control, irrigation records, and zone management.
- May already have greenhouse hardware but lacks control and monitoring.
- Needs stability, repeatability, alarms, and data visibility.
- Often compares scheduled fertigation versus EC/pH closed-loop control.

### Goals

- Understand greenhouse irrigation and fertigation options.
- See how fertigation, valves, sensors, and monitoring connect.
- Identify suitable controller modules.
- Start with an upgrade, demo project, or full system.

### Recommended Entry Pages

- Home
- Greenhouse Irrigation
- Greenhouse Fertigation Climate Control
- Fertigation System
- EC/pH Controller
- Modular Fertigation Control landing page
- Fertigation Upgrade landing page
- Contact

### Navigation Path

Home
→ Solutions
→ Greenhouse Irrigation
→ Fertigation System
→ Product modules
→ Contact

Alternative path:

Landing page
→ Fertigation System
→ EC/pH Controller
→ Contact

## System Integrator

### Problems

- Needs a technical system structure before selecting products.
- Needs wiring logic, control architecture, LoRa field device planning, and integration options.
- Needs confidence that PKYDrip modules can fit local installation conditions.
- May need technical support for commissioning and project communication.

### Goals

- Understand the architecture.
- Match system modules to project scope.
- Review products and technical resources.
- Contact PKYDrip for drawings, pricing, and project support.

### Recommended Entry Pages

- Home
- Systems
- Irrigation Control System
- Wireless Irrigation System
- Fertigation System
- Monitoring & Sensors as a supporting module
- Products
- Docs / Guides / Tools
- Contact

### Navigation Path

Home
→ Systems
→ Relevant System page
→ Products
→ Resources
→ Contact

Alternative path:

Home
→ Products
→ Related System
→ Technical Resources
→ Contact

## Distributor

### Problems

- Needs to understand whether PKYDrip can support local selling, local installation, and after-sales service.
- Needs clear product families and system packages.
- Needs campaign-ready pages and demo materials.
- Needs to know whether cooperation is exclusive, regional, or project-based.

### Goals

- Understand product/system range quickly.
- Identify market-fit systems for local farms and contractors.
- Start with sample order, demo system, or first cooperation project.
- Discuss dealer/partner pricing and support.

### Recommended Entry Pages

- Systems
- Products

- Downloads
- Contact

## OEM Partner

### Problems

- Needs control hardware, branding options, engineering support, and modular product structure.
- Needs to understand what can be customized.
- Needs confidence that PKYDrip can support project-based or market-specific cooperation.
- May care more about integration and manufacturing support than retail product pages.

### Goals

- Understand PKYDrip system and product modules.
- Review OEM/manufacturing capabilities.
- Identify which controllers, gateways, cabinets, or fertigation modules can be adapted.
- Start technical/business discussion.

### Recommended Entry Pages

- Home
- Systems
- Products
- OEM Irrigation Controller landing page
- OEM Manufacturing docs
- Farm Control Platform / strategy page
- Contact

→ Contact

→ Contact

## Journey Design Principles

- Farm owners should enter through Solutions first, then Systems, then Contact.
- Greenhouse growers should enter through Greenhouse/Fertigation pages, then product modules.
- System integrators should enter through Systems first, then Products and Resources.
- Distributors should enter through Systems and Demo/Partner pages.
- OEM partners should enter through Systems, Products, and OEM-specific Resources or Landings.

## Future Internal Link Rules

- Every Solution page should link to at least one System page.
- Every System page should link to recommended Product pages.
- Every Product page should link back to its parent System.
- Every Landing page should link to one canonical System or Solution page.
- Every Resource page should identify related Systems, Solutions, and Products.
- Demo pages should link to the Systems and Solutions they demonstrate.
