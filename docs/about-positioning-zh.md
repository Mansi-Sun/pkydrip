# About Us 中文主稿

## 公司定位
PKYDRIP 是一家专注于水肥灌溉技术应用的公司。

从种植作物、面积和灌溉条件出发，我们将水泵、管路、施肥设备、传感器与控制系统组合成适合项目的设备方案。通过设备组装、测试和直接技术支持，帮助种植者、工程商及合作伙伴完成选型、安装、使用与改进。具体支持范围按项目确认。

研发、硬件、软件和系统集成围绕实际应用展开。不能单凭种植面积选型，还应结合灌溉分区、流量、压力和运行条件。

## 应用工作
1. 从作物、种植方式、面积及现有设备了解需求。
2. 根据水源、管路、高差及同时运行的分区讨论水泵和流量压力。
3. 以 FG301、FG501 平台讨论施肥通道、预混罐、配方与 EC/pH 控制，具体功能按配置确定。
4. 正在搭建试验台，计划开展水泵、流量、压力和配肥系列测试，记录工况与结果，积累数据。可演示内容提前确认，不宣称全部测试已经完成。
5. 直接提供组装、安装和使用方面的技术沟通，文档与培训范围按项目确认。
6. 按配置可从 1–3 套水肥机开始，开展定制、OEM 或代理合作，MOQ 与支持范围在订购前确认。
