# PKY-ECPH-02 系统示意图

本文档说明 PKY-ECPH-02 在营养液混液系统中的设备组成、连接关系与工作流程。

## 系统组成

| 组件 | 说明 |
| ---- | ---- |
| **PKY-ECPH-02 控制器** | 核心控制单元，带触摸屏 HMI。读取 EC/pH 探头信号，控制各泵和阀门 |
| **EC 探头** | 安装在混液桶内，实时测量营养液 EC 值 |
| **pH 探头** | 安装在混液桶内，实时测量 pH 值 |
| **混液桶** | 营养液混合与检测容器，所有肥液在此混合 |
| **搅拌泵** | 保持桶内液体均匀，确保 EC/pH 读数准确 |
| **A 液加药泵** | 注入 A 肥液（通常为母液 A 通道） |
| **B 液加药泵** | 注入 B 肥液 |
| **C 液加药泵** | 注入 C 肥液 |
| **pH 调节泵** | 注入酸液或碱液，调节 pH |
| **进水电磁阀** | 控制清水进入混液桶，用于补水或稀释 |
| **出水口** | 调节达标后的营养液由此输送至灌溉系统 |

---

## 连接关系

**混液桶侧：**

- EC 探头、pH 探头浸没于桶内液体
- 搅拌泵出口指向桶内，促进混合
- A / B / C 加药泵及 pH 调节泵出口接入桶内
- 进水电磁阀接清水管，出水口接下游灌溉管路

**控制器侧：**

- EC 探头、pH 探头信号线接入控制器
- A / B / C 加药泵、pH 调节泵、搅拌泵、进水电磁阀的控制线接入控制器对应输出端子

> 具体端子编号请参阅设备接线图或安装手册，本文不展开电气细节。

---

## 工作流程

```text
进水 → 混液桶 → EC/pH 检测 → 自动加液 → 搅拌混合 → 达标后供液
```

**分步说明：**

1. **进水** — 必要时进水电磁阀打开，向混液桶补充清水。
2. **混液桶** — 所有肥液和调节液在桶内混合。
3. **EC/pH 检测** — 探头连续或周期性读取数值，显示于 Monitoring 页面。
4. **自动加液** — EC 偏低时依次启动 A/B/C 泵；pH 偏离目标时启动 pH 调节泵。
5. **搅拌混合** — 每次加液后搅拌泵运行 Mixing Time 所设时长，使浓度均匀。
6. **达标后供液** — EC 和 pH 进入目标区间后，营养液从出水口输送至灌溉系统。
