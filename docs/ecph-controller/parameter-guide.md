# PKY-ECPH-02 参数配置说明

本文档详细说明 **Parameter Set（参数配置）** 页面中各项参数的含义、默认值与建议设置范围。面向现场操作员与代理商，帮助您快速完成配方配置。

> 修改参数后请务必 **Save（保存）**，再返回 Monitoring 页面启动自动运行。

---

## 页面概览

Parameter Set 页面通常分为 **EC 参数区** 和 **pH 参数区**，部分版本还包含 **通用参数**（Controller Mode、Temperature、Reading Time 等）。

## EC 参数表

| 参数名称 | 默认值 | 建议范围 | 说明 |
| -------- | -----: | -------: | ---- |
| **EC Set Value** | 2.0 | 0.8 – 4.0 | EC 目标值（mS/cm 或 EC 单位，与探头标定一致）。控制器将 EC 维持在此值附近。叶菜类常见 1.2–2.0，果菜类常见 2.0–3.5，请按作物配方填写。 |
| **EC Safety Range** | 0.2 | 0.1 – 0.5 | EC 回差（死区）。仅当 EC **低于**「EC Set Value − 本值」时才启动加肥；EC 进入目标区间后停止。值过小会导致泵频繁启停，过大则调节偏慢。 |
| **EC Ratio** | 1.0 | 0.1 – 10.0 | A/B/C 肥液通道的配比系数。若 A:B:C 配方为 1:1:1，通常均设为 1.0；若某通道浓度不同，按实际配方比例调整。 |
| **EC AL** | 0.5 | 0.3 – 1.5 | EC 报警下限（Alarm Low）。EC 低于此值触发报警，提醒营养液过稀或探头异常。应低于 EC Set Value。 |
| **EC AH** | 4.0 | 2.5 – 6.0 | EC 报警上限（Alarm High）。EC 高于此值触发报警，提醒加肥过量或探头故障。应高于 EC Set Value。 |
| **EC Max-Number** | 10 | 3 – 30 | 单次 Start 运行周期内，EC 加肥循环的最大次数。达到上限后停止加肥并报警，防止因探头故障或配方错误无限加肥。 |
| **EC One-Time** | 5 | 1 – 30 | 每次启动单个加药泵的运行时间（秒）。按泵流量和桶容积调整：流量小可适当加长，流量大应缩短以防一次加过量。 |
| **EC Mixing Time** | 60 | 20 – 180 | 每次加肥后等待搅拌混合的时间（秒）。必须足够让桶内 EC 均匀后再读数，否则读数不准会导致重复加肥。 |
| **EC Alarm Mode** | 声光 | — | EC 报警输出方式。常见选项：声光报警、仅屏幕提示、继电器输出等，视安装版本选择。 |
| **Controller Mode** | Auto | — | 控制器总模式。**Auto（自动）**：按 EC/pH 设定自动调节；**Manual（手动）**：仅 Manual 页面控制输出；调试阶段可选手动。 |
| **Temperature** | 25 | 10 – 40 | 温度补偿参考值（℃）。用于 EC 读数温度补偿，一般设为当地常用水温或默认 25℃。 |
| **Reading Time** | 10 | 5 – 60 | 传感器读取间隔（秒）。每隔此时间读取一次 EC/pH。过短增加探头损耗，过长则调节响应变慢。 |

### EC 参数设置步骤

1. 根据作物配方填写 **EC Set Value**。
2. 设置 **EC Safety Range**（建议先从 0.2 开始）。
3. 按 A/B/C 肥液配方设置 **EC Ratio**。
4. 设置 **EC One-Time** 和 **EC Mixing Time**，在 Manual 页面实测一次加肥量是否合适。
5. 设置 **EC AL / EC AH** 作为安全边界。
6. 保存并返回 Monitoring 试运行。

## pH 参数表

| 参数名称 | 默认值 | 建议范围 | 说明 |
| -------- | -----: | -------: | ---- |
| **PH Set Value** | 6.0 | 5.0 – 7.0 | pH 目标值。大多数作物适宜 5.5–6.5，请按配方填写。 |
| **PH Safety Range** | 0.2 | 0.1 – 0.5 | pH 回差。仅当 pH 偏离目标超过此值时才启动调节泵，避免 pH 在目标值附近频繁动作。 |
| **PH AL** | 4.5 | 4.0 – 5.5 | pH 报警下限。低于此值触发报警，防止 pH 过低伤害根系。 |
| **PH AH** | 7.5 | 6.5 – 8.5 | pH 报警上限。高于此值触发报警，防止 pH 过高导致养分失效。 |
| **PH Max-Number** | 8 | 3 – 20 | 单次运行周期内 pH 调节的最大次数。达到上限后停止并报警。 |
| **PH One Time** | 3 | 1 – 15 | 每次启动 pH 调节泵的运行时间（秒）。pH 调节敏感，建议从较短时间开始，逐步微调。 |
| **PH Mixing Time** | 45 | 20 – 120 | 每次 pH 调节后等待混合的时间（秒）。pH 变化需要充分混合后才准确，不可过短。 |
| **PH Alarm Mode** | 声光 | — | pH 报警输出方式，与 EC Alarm Mode 类似。 |
| **PH Control Mode** | 双向 | — | pH 控制方向：**仅加碱**（pH 低时加碱液）、**仅加酸**（pH 高时加酸液）、**双向**（自动判断）。须与现场安装的调节液类型一致。 |

### pH 参数设置步骤

1. 确认现场安装的是酸液还是碱液（或两者均有）。
2. 选择正确的 **PH Control Mode**。
3. 填写 **PH Set Value** 和 **PH Safety Range**。
4. 设置 **PH One Time** 和 **PH Mixing Time**，Manual 页面短测 pH 变化幅度。
5. 设置 **PH AL / PH AH** 安全边界。
6. 保存，校准探头后试运行。

## 参数之间的关系

理解以下关系，可避免常见配置错误：

```
EC 启动加肥条件：当前 EC < EC Set Value − EC Safety Range
EC 停止加肥条件：当前 EC ≥ EC Set Value（进入目标区间）

pH 启动调节条件（加碱）：当前 pH < PH Set Value − PH Safety Range
pH 启动调节条件（加酸）：当前 pH > PH Set Value + PH Safety Range
```

- **EC Mixing Time** 与 **EC One-Time** 配合使用：加肥 → 混合 → 读数 → 判断是否继续。
- **Max-Number** 是安全阀：无论读数是否达标，达到次数上限即停止。
- **AL / AH** 是报警边界，与正常调节区间不同；超出 AL/AH 会报警，但不一定触发加肥。
