# PKYDrip 水肥机型号编码规范（V1.0）

## 1. 原则

- 对外型号保持简短、稳定：`PKY-FG301`、`PKY-FG401`、`PKY-FG501`。
- 第一位数字表示总加药通道数，包含肥料和酸/碱通道。
- 公开型号与订单配置码分离，避免每次定制都变成新产品。
- 标准选配直接编码；特殊开发必须经过技术评审、MOQ 和工程范围确认。

## 2. 公开型号

`PKY-FG[通道数][代次]-[控制]-[水路]`

| 字段 | 代码 | 含义 |
|---|---|---|
| 平台 | FG301 / FG401 / FG501 | 3 / 4 / 5 个总加药通道 |
| 控制 | B / M / A / AR | 基本 / 监测 / EC-pH 自动 / 自动加配方 |
| 水路 | DI / MT | 直注式 / 混肥桶式 |

## 3. 订单扩展码

推荐顺序：`[平台]-[机械平台]-[控制]-[水路]-[场景]-[流量]-[电压]-[特殊状态]`

| 类别 | 代码示例 | 含义 |
|---|---|---|
| 机械平台 | P / D / H | 蠕动泵 / 隔膜泵 / 大流量工程平台 |
| 场景 | OF / GH / OR / HY / LB | 大田 / 温室 / 果园 / 水培 / 实验室 |
| 流量 | Q80-100 | 设计流量 80–100 m³/h，必须经选型确认 |
| 电压 | V380-440 | 订单电压范围，必须与电机、电控一致 |
| 状态 | STD / SP01 / EVT | 标准 / 已批准特殊版本 / 工程验证版本 |

## 4. 示例与使用规则

- `PKY-FG401-P-A-MT-GH`：四通道、蠕动泵、EC/pH 自动、混肥桶、温室。
- `PKY-FG501-AR-MT-HY`：五通道、配方管理、自动闭环、混肥桶、水培。
- `PKY-FG401-H-B-DI-OF-Q80-100-V380-440`：四通道大流量大田工程配置；流量和电压不是所有 FG401 的固定参数。
- 网站、目录、广告优先使用公开型号；报价单写完整配置码。
- 特殊要求先分配 `SPxx`，明确 MOQ、工程费、交期和验收边界。
- OEM 能力在独立页面说明，不在每个产品页承诺无条件定制。
