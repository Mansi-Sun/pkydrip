Company introduction

PKYDrip focuses on irrigation automation: scheduling, pump and valve coordination, sensor feedback, fertigation logic, and optional wireless field layers. Work is structured for integrators, contractors, distributors, and OEM partners who need repeatable control hardware and clear system boundaries.

Typical scope includes controller and cabinet delivery, I/O and protocol interfaces for pumps and valves, documentation for commissioning, and paths to expand from timed irrigation to sensor-driven or remote operation.

  • Modular control building blocks rather than single-SKU “one box does all” claims
  • Emphasis on hydraulic + electrical constraints encountered in real projects
  • Support for staged upgrades (pump → zones → wireless → fertigation) where the site already has mains and valves

Irrigation retrofit & automation

Many sites retain existing wells, pumps, mains, and manual valves. Retrofit work targets control and zoning: add controller logic, pump start/stop rules, automated valve sequencing, schedules, and records—without replacing the full pipe network when it is still serviceable.

  • Pump interlocks and time windows matched to available flow
  • Zone-by-zone sequencing instead of ad-hoc manual switching
  • Optional expansion to remote or wireless valves where trenching is costly
Reference Irrigation retrofit & upgrade

Control cabinets & pump control

Control panels and cabinets consolidate power, I/O, and application logic for pump start/stop, valve drivers, operator interface (e.g. touchscreen), and field wiring termination. Delivery is aligned with project electrical standards and cabinet environmental requirements.

  • Relay or contactor interfaces matched to existing motor / starter arrangements
  • Pressure / flow inputs where the specification requires feedback
  • Structured documentation for integrators commissioning on site
References Irrigation control cabinet · Irrigation control panel · Irrigation automation & control

Fertigation systems

Water–fertilizer integration covers injection, mixing, and closed-loop EC/pH where the crop and irrigation method require stable nutrient delivery tied to irrigation events. Systems are described in modular terms: channels, sensors, interlocks with irrigation schedules, and alarm / limit handling appropriate to greenhouse and field projects.

  • Scheduled fertigation vs closed-loop regulation (project-dependent)
  • Coordination with main irrigation controller and pump run conditions
  • Instrumentation for EC, pH, and flow where specified
References Water–fertilizer integration system · Fertigation system category

Wireless / LoRa irrigation

Where cable pulls are expensive or retrofit windows are short, a gateway + field node architecture can distribute valve commands and status without trenching to every solenoid. Design emphasis: range planning, power (solar / battery), duty cycle, and fallback operation.

  • Central gateway for schedules and coordination with existing pump logic
  • Nodes at valve manifolds; expansion by adding nodes, not rewiring the farm
  • Suitable for open-field layouts documented on the LoRa solution page
References LoRa wireless irrigation control · Open-field irrigation

OEM / custom development

OEM engagement covers hardware variation, branding, firmware behaviour, and interface agreed per project or product line—not generic rebranding only. Typical deliverables: cabinet or PCB spin, HMI definitions, protocol exposure (e.g. RS485/Modbus), test records, and batch manufacturing support.

  • Controller and cabinet variants for regional electrical and environmental norms
  • Integration support for partner cloud or SCADA where specified
  • MOQ and roadmap items negotiated per partner; see public OEM documentation
