# PKYDrip Engineering Lab (Public)

**Website:** https://lab.pky-dripirrigation.com/  
**Contact (technical feedback / collaboration):** junfeng@pky-dripirrigation.com

PKYDrip Engineering Lab is a public engineering workspace for irrigation automation.
It publishes free tools, quick reference tables, architecture notes, protocol mapping drafts,
and field experiment logs for landscape and agricultural irrigation projects.

This is **NOT** a product catalog.  
It is a technical reference layer that will be continuously expanded.

---

## What you can find

- **Tools** (`/tools/`)
  - Pump sizing calculator and quick charts
  - Solar irrigation sizing notes/tools
  - Zoning & sequencing templates

- **Architecture** (`/architecture/`)
  - Pump + valve sequencing logic
  - Zoning strategies
  - Safety logic and protection concepts

- **Protocols** (`/protocols/`)
  - RS485 / Modbus mapping notes
  - LoRa topology and range considerations
  - MQTT topic/payload drafts (for integration)

- **Experiments** (`/experiments/`)
  - Demo rack / showroom rig build logs
  - Range tests and practical notes
  - Iteration logs
